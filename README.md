## 🌟 Overview

A modern, high-performance personal portfolio website built with **React**, **TypeScript**, **Tailwind CSS**, and **Vite**. Strictly crafted from verified CV achievements, authentic project repositories, and structured case studies.

### Key Highlights
- **Flagship Case Study**: Deep dive into the *AI-Powered Customer Service Call Analysis* system (Egyptian Arabic speech transcription, Whisper / Faster-Whisper benchmarking, Speaker Diarization, AraBERT sentiment analysis, and decoupled Django + FastAPI architecture).
- **Project Hierarchy**: High-priority cards for award-winning work (StudyFlash — Top 15 in DEPI Mobile Track), hackathon projects (I'Supply delivery notifications), and verified GitHub repositories.
- **Production SEO & Web Vitals**: Full JSON-LD (Schema.org Person, WebSite, SoftwareSourceCode), OpenGraph, Twitter Cards, `robots.txt`, and XML `sitemap.xml`.
- **Accessibility & UX**: Dark/light mode persistence, keyboard navigation, `prefers-reduced-motion` compliance, and screen-reader accessible semantic HTML5.
- **Authentic Assets**: Real headshot, integrated downloadable PDF resume, and verified GitHub & LinkedIn profile links.

## 🚀 Quick Start

### 1. Install Dependencies
```bash
npm install
```

### 2. Start Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
Generates an optimized static bundle in `dist/`.

### 4. Preview Production Build
```bash
npm run preview
```
